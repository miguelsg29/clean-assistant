Mapas de la casa

Clean Assistant recuerda los mapas que va viendo. Pulsa uno para activarlo en el robot. (Al cambiar de mapa, las zonas y horarios son por mapa.) Puedes borrar cualquier mapa; si borras el último, el robot se queda sin mapa y podrás crear uno nuevo desde cero.

Al crear, el robot recorrerá toda la casa para mapearla (tarda un rato). El mapa nuevo empieza en blanco (sin zonas ni horarios).

¡Bienvenido a Clean Assistant!

Controla tu Conga 100% en local, sin la nube de Cecotec. Solo hay que hacer dos cosas:

1 Redirige el DNS del robot a este servidor

El robot busca la nube de Cecotec en unos dominios fijos. Para que hable con Clean Assistant, redirígelos a la IP de este servidor con tu bloqueador de DNS (AdGuard Home, Pi-hole) o el router:

Dominiotcp-cecotec.3irobotix.net
Apunta a…

Con ese basta para controlar el robot. Para 100 % local (sin depender nunca de Cecotec), redirige también estos a la misma IP:

AdGuard Home: Filtros → Reescrituras DNS → Añadir (Dominio e IP). Pi-hole: Local DNS → DNS Records. Muchos routers: DNS estático / entrada de host local. Luego reinicia el robot (apágalo y enciéndelo) para que reconecte aquí.

⏳ Esperando a que el robot conecte…
2 Crea el mapa de tu casa

⚠ Al crear el mapa se borrarán los mapas, zonas y horarios que el robot tenga ahora, para empezar de cero con uno solo. El robot recorrerá toda la casa (tarda un rato).
